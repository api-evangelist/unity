Unity's AI tools in beta includes a 3D Object Generator capable of creating static 3D mesh prefabs from text prompts or reference images. Generated objects are single-part, non-rigged props suited to environment details, household items, and decorative assets. Generate directly from the Generators window or through the in-editor AI Assistant using natural language.
